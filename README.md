An insurer receives about 20,000 claims per month by email, portal upload, and post (scanned). 
Each claim contains invoices, medical reports, and sometimes forms with handwritten fields. 
Today, case handlers spend roughly 15 to 25 minutes per claim reading documents, checking the policy,
checking for inconsistencies or fraud signals, and drafting a decision or a request for more information.
Backlogs cause slow payouts and customer complaints.

An insurer would be Allianz, Axa, etc
Case Handler is the sachbearbeiter.

The Business Workflow of the claims Management contains manual work that can be fully automated with a Multi Agent System.
